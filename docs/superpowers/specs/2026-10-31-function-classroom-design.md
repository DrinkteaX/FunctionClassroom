# 函数课堂设计规格

**制作：雾雨魔理沙**

简述：Windows 10 希沃大屏触控函数绘图软件，强调多函数、交点、参数演示和低部署成本。

## 目标

为 Windows 10 希沃大屏制作一个离线、触控优先的高中函数绘图工具。教师不连接键盘和鼠标，也能输入多个函数、比较图像、查看交点、调整参数、进入课堂演示并导出图片。

首版是单窗口 WPF 应用，使用 Windows 10 自带的 .NET Framework 4.8 运行库，不使用 NuGet、Electron、WebView2、Python、Node.js 或其他需要额外安装的运行时。

## 全局约束

- 目标系统：Windows 10 64 位。
- 技术栈：C# 5、WPF、.NET Framework 4.x 系统运行时。
- 不引入第三方 DLL。
- 主要输入方式：手指或触控笔；鼠标和实体键盘可选。
- 多函数：最多同时显示 6 条曲线。
- 交点：只计算当前视窗范围内指定两条函数的近似交点，也支持与 x 轴求交。
- 表达式：只接受显函数 `y=f(x)`，支持数字、`x`、参数 `a` 至 `k`、括号、四则运算、乘方、常见常数和函数。
- 可执行程序以简单文件夹形式交付，无安装器、无管理员权限、无联网依赖。

## 课堂流程

1. 启动应用，默认建立 `f₁(x)=x²`。
2. 通过大尺寸公式键盘或实体键盘编辑表达式。
3. 新增函数并在同一坐标系绘制，所有可见函数共享缩放和平移。
4. 触摸曲线查看坐标，或拖动自动生成的参数滑块。
5. 选择两条函数查找交点，或查找函数与 x 轴的交点。
6. 使用模板快速加入二次、指数、对数、三角等常见函数。
7. 进入演示模式隐藏编辑栏，或导出 PNG、复制图像到剪贴板。

## 功能需求

### 函数输入

- 表达式支持 `2x`、`3(x+1)` 这样的隐式乘法。
- 支持 `+ - * / ^`、括号、小数和科学计数法。
- 支持 `pi`、`π`、`e`。
- 支持 `sqrt`、`abs`、`sin`、`cos`、`tan`、`ln`、`log`、`log10`、`exp`。
- 支持 `asin`、`acos`、`atan`。
- 参数变量名区分大小写，滑块自动覆盖表达式中的参数。
- 非法表达式显示明确错误，不执行任意代码。

### 绘图

- 根据横向像素采样函数，样本之间使用折线连接。
- 非有限值、定义域跳变、渐近线附近拆分为不同路径。
- 坐标轴、网格、刻度随缩放更新。
- 单指平移、双指缩放，也提供按钮缩放和复位。
- 最多六条曲线，每条有独立颜色和可见状态。
- 显示当前触摸点坐标。

### 交点

- 选择两条函数后计算当前视窗内的所有近似交点。
- 与 x 轴求交时把第二条函数视为零函数。
- 使用差值采样和二分法精化。
- 使用局部极小值辅助识别相切点。
- 对无定义、重复点、密集点和函数重合作防护。

### 模板、演示和数据

- 提供二次函数、反比例函数、指数函数、对数函数、正弦函数模板。
- 模板包含公式和简短数学性质，不显示幼稚提示。
- 演示模式隐藏编辑栏并扩大绘图区。
- 自动保存最近一次工作区到用户本地应用数据目录。
- 可导出 PNG，可复制当前绘图区图像到 Windows 剪贴板。

## 界面

- 左侧为函数列表，中央为绘图区，底部为公式键盘抽屉，顶部为精简工具栏。
- 主要按钮最小高度 48 像素，公式键盘按键最小高度 54 像素。
- 使用深色文字、浅色背景和高对比曲线颜色。
- 不依赖悬停提示，不要求长按。
- 交点圆点具有较大点击热区。

## 错误和边界

- 单个函数错误不能阻断其他函数绘制。
- 浏览无交点时显示“当前视野内没有交点”。
- 重合函数提示重合，不返回无限交点列表。
- 最大交点数量为 120，防止密集振荡导致界面卡顿。
- 应用启动时若自动保存损坏，回退到默认函数。

## 验收

- 不连接键盘鼠标可以完成核心课堂流程。
- 六条常见函数同时平移保持可用流畅度。
- `x^2=0` 的相切零点可被找到。
- `y=x^2-4` 与 `y=0` 找到约 `(-2,0)` 和 `(2,0)`。
- `1/x` 不出现穿过渐近线的错误曲线。
- 导出 PNG 和复制剪贴板成功。
- 构建产物不包含第三方运行时，也不要求网络。
